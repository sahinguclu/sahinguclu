Authlama

Concept

A serverless, zero-database encrypted TOTP code manager. Save your 2FA codes as a single encrypted file. Nothing is stored anywhere.

authlama.pages.dev Source Code

Why Authlama?

Your 2FA codes deserve real protection. Save them in the cloud - you trust a third party. Save them on your device - you lose everything if it breaks. Authlama gives you a single encrypted file: secret.txt. That file is your vault. AES-256-GCM encrypts every code inside. No server. No database. No account. You hold the key. You make the rules.

Key Features

  • 🔐 TOTP code generation - scan QR codes or enter secrets manually
  • ⚡ Session mode - codes disappear when you close the tab
  • 🛡 AES-256-GCM encryption via Web Crypto API
  • 🔑 Password protection with PBKDF2 (600,000 iterations)
  • 📥 Download as secret.txt - save the encrypted key anywhere
  • 📤 File upload to unlock - upload secret.txt + password
  • 🔄 Re-encrypt on edit - new key invalidates old one
  • 🌓 Dark / Light mode with localStorage persistence
  • 🧹 Auto-cleanup on exit - all session data wiped

Gizlock

Concept

A serverless, zero-database encrypted publishing tool. Write a page. Share a link. Nothing is stored anywhere.

gizlock.pages.dev Source Code

Why Gizlock?

Every time you publish, you hand your words to a platform. They can delete your post. Suspend your account. Shut down entirely. Gizlock removes storage. Your article lives inside the link itself - compressed, encrypted with AES-256-GCM. The link is the article. No server holds it. No one can take it down. There is nothing to take down.

Key Features

  • 🚫 Zero accounts - no sign-up, no login, no tracking
  • 💾 Zero server storage - content never touches a database
  • 🔒 AES-256-GCM encryption - client-side, Web Crypto API
  • 🔑 Password protection via PBKDF2 (100,000 iterations)
  • ⏱ Time-locked access - Valid From / Valid Until dates
  • 🕐 NTP-verified time - checked against real internet time servers
  • ✍ Rich text editor - bold, italic, headings, lists, images
  • 🔗 Auto-linking - pasted URLs become clickable on publish
  • 🗜 LZString compression - keeps links as short as possible

HypeVox

Audio control for any browser tab - volume up to 1000%, 12 sound profiles, 54 languages, and zero trackers.

Chrome Web Store Source Code

Why HypeVox?

Take control of audio in any browser tab. Boost volume up to 1000%. Apply one of 12 sound profiles - Bass, Voice, Treble, Podcast, and more. Works in 54 languages. Zero trackers. Zero telemetry. Just audio, under your control.

Key Features

  • 🔊 Volume Boost - Mute (0%) to 1000% on any tab
  • 🎛 12 Sound Profiles - Bass, Voice, Treble, Podcast, Rock, Pop & more
  • 🌓 Dark Mode - Toggle light/dark, preference saved
  • ⌨ Keyboard Shortcuts - 0-8 for landmarks, arrows for fine control
  • 🔉 Audible Tabs - See and switch to any tab playing audio
  • 🌍 54 Languages - Full UI translations
  • 🛡 Zero Trackers - No analytics, no telemetry, no external calls
